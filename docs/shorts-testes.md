# Roteiro de testes manuais do Shorts

| Teste | Resultado esperado |
|---|---|
| Abrir `#/shorts` | O primeiro Short toca e a barra de progresso avança |
| Girar a roda do mouse para baixo | Passa para o próximo Short, um por gesto |
| Teclas ↑ e ↓ | Voltam e avançam um Short |
| Espaço ou K | Pausa e retoma o Short |
| Curtir | O número sobe e o botão fica marcado; continua após recarregar |
| Inscrever-se | O botão vira "Inscrito" e o canal entra no menu lateral |
| Comentar | O comentário aparece no painel e o contador aumenta |
| Abrir `#/shorts/s08` | Começa direto no Short s08 |
| Rolar 60 Shorts seguidos | A lista continua e a tela não pula |
| Botão voltar do navegador | Volta para a página anterior |
| Tela de celular (até 700 px) | Short em tela cheia e comentários em gaveta |
| Enviar vídeo de até 60 s | O vídeo aparece nos Shorts e tem botão de som |
